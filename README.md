# SFX Studio

A professional Sound Design / SFX Library Plugin for Adobe Premiere Pro.

## How to test SFX Studio in Premiere Pro

1. Double-click `Open-SFX-Studio.bat` from Windows Explorer.
2. Wait for the "SUCCESS: SFX Studio is Ready!" message.
3. Open or restart **Adobe Premiere Pro**.
4. Go to **Window → Extensions → SFX Studio**.

*Note: The launcher automatically handles the build process, registry settings (PlayerDebugMode), and extension installation.*
